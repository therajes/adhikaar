# Claims register

ADHIKAAR can demonstrate that evidence was signed by an enrolled key; determine whether every requested action is explicitly permitted by a signed policy; bind a short-lived proof to a receiver challenge; detect the defined tamper, expiry, replay, revocation, stale-root, and registry mismatch fixtures; and witness trust-state hashes through two-of-three local consortium governance.

ADHIKAAR does not claim to be the first authorization protocol, a production national registry, legally authoritative, completely immutable, able to prevent all impersonation scams, able to authenticate the telephone network, or able to identify every compromised endpoint.
